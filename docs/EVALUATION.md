# Проверки существующего checkpoint

Кандидат: attention-r3-s45. Исходник: DeepSeek V4.1 Flash, revision `dba1be0a40aa45a94ad051997016db3960a90277`.

На исходной и изменённой моделях выполнены одинаковые 90 вопросов: по 30 из MMLU-Pro, GPQA Diamond и GSM8K flexible. MMLU и GSM использовали 5 отдельных решённых примеров, GPQA — без примеров. Thinking effort75, temperature0, output16384, context32768, DSpark5, четыре клиента. Оценивался только final по эталону; исчерпание лимита считалось ошибкой.

У каждой модели пять GPQA без final из-за лимита. В MMLU-Pro и GPQA есть по одному вопросу, верному только у исходника, и по одному — только у изменённой модели. Одинаковый итог не означает одинаковые ответы или доказанную эквивалентность. Это маленькие выборки, не полный leaderboard. Агрегаты находятся в `quality-summary.json`; приватные тексты и reasoning сюда не включены.

Serving проверен на 4×H200 SXM, TP4/EP4, private pinned CPU Engram, DSpark block5. После перехода на context262144/token pool1048576/chunked prefill2048 выполнен нейтральный запрос с 250079 входными токенами и thinking75. Получен правильный контрольный marker; генерация заняла75.75секунды, наблюдавшийся минимум свободной GPU-памяти — около49GiB на GPU. Это тест вместимости на заполнителе, не оценка качества длинного анализа. Полный контекст1M не проверен.

Pi прошёл короткий тест потокового ответа с одним вызовом read. Полноценный набор coding-agent, vision и tool-use задач не оценивался.

`weights/bundle.json` сохранён в исходном виде. Его `pilot_accepted=false` и `qualification="untested candidate; thinking evaluation required"` отражают момент создания patch до последующих проверок. Файл не переписан задним числом; актуальные ограниченные результаты приведены здесь.

Пакетирование в этот репозиторий не меняет веса. Новый сборщик проверен на небольших синтетических safetensors: замена нужных значений, сохранность исходника и незатронутых тензоров, контроль хэшей, защита от записи внутрь исходника, режим копирования и обнаружение LFS pointer. Полный checkpoint уже собирался исходным merger в рабочем эксперименте; повторная сборка510GB исходника новой упакованной версией скрипта не проводилась.
